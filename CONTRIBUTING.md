# Contributing

Please describe the problem, your Windows and Codex versions, and a minimal reproduction. Review screenshots, logs, paths, account details and usage values before posting; never share authentication files or tokens.

For changes, build with `scripts/Build.ps1` on 64-bit Windows and describe the behavior you verified. Changes to window positioning should cover moving, minimizing, restoring, and Codex update-button overlap. Keep releases free of account data and generated runtime logs.
